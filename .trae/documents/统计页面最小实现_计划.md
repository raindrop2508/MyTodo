# 统计页面最小实现计划

## Summary
- 目标：根据 `docs` 设计文档、`mypotato-focus-flow-main` 的 Web 原型以及用户给定截图，将 Android 端统计页从占位页改为“可演示的最小实现”。
- 本次时间维度明确采用：`日 / 月 / 年`，不保留周视图。
- 本次范围：
  - 顶部标题
  - `日 / 月 / 年` 切换
  - KPI 卡片：专注时间、完成数
  - `日` 视图：半小时粒度的纵向时间流
  - `月 / 年` 视图：按类别堆叠的轻量柱图
- 实现边界：使用静态假数据，不接 Room、不接真实 Repository、不引入第三方图表库。

## Current State Analysis
- `app/src/main/java/com/gordon/mypotato/ui/statistics/StatisticsFragment.kt` 当前仅为 `Fragment(R.layout.fragment_statistics)`，没有任何状态、绑定或渲染逻辑。
- `app/src/main/res/layout/fragment_statistics.xml` 当前只有一个居中的占位 `TextView`，无法承载统计页的筛选、卡片和图表结构。
- `docs/ui-skeleton-android/page_design.md` 中 Statistics 页要求包含：顶部标题、时间筛选、指标卡片、图表容器，并建议使用 `MaterialCardView` 承载统计模块。
- `docs/ui_skeleton/UI骨架验收清单.md` 对 Statistics 页的最低要求包括：时间维度切换存在、模块容器存在、统计口径表达明确。
- Web 原型 `mypotato-focus-flow-main/src/pages/Stats.tsx` 使用的是 `daily / weekly / monthly` 与多图表组合，但本次需求已明确改为 `日 / 月 / 年`，因此只能参考其信息层级和卡片布局，不能直接照搬时间维度和图表类型。
- 当前 Android 工程中没有现成的统计数据源、图表库封装或统计自定义 View，可用方案是：纯 XML 布局 + Fragment 内部假数据 + 轻量自绘 View。

## Proposed Changes

### 1. 重构 `app/src/main/res/layout/fragment_statistics.xml`
- 将根布局改为 `NestedScrollView` + 垂直内容容器，保证小屏可滚动。
- 顶部区域放置：
  - 左上主标题 `统计`
  - 副标题 `专注概览` 或当前维度说明
- 标题下方增加 `MaterialButtonToggleGroup` 或等效的 3 个单选按钮：
  - `日`
  - `月`
  - `年`
- 切换组下方增加两个 KPI 卡片：
  - `专注时间`
  - `完成数`
- 主内容区拆为两套容器，按当前维度切换显示：
  - `layout_daily_timeline_container`：用于日视图时间流
  - `layout_chart_container`：用于月/年堆叠图
- 图表区域下方预留图例容器：
  - 多类别时显示颜色图例
  - 单类别时可隐藏或仅显示单一标签
- 视觉风格保持与 `fragment_today.xml`、`fragment_settings.xml` 已落地页面一致：
  - 16dp 外边距
  - 24dp 左右圆角卡片
  - `?attr/colorSurface` / `?attr/colorOnSurface` / `?attr/colorOutlineVariant`

### 2. 扩展 `app/src/main/res/values/strings.xml`
- 新增统计页所需文案资源：
  - 页面标题、副标题
  - `日 / 月 / 年` 切换文案
  - KPI 标题文案
  - 日视图区块标题
  - 月/年图表标题
  - 图例标签与空态文案
- 所有用户可见文案均放入资源文件，不在 Kotlin 中硬编码。

### 3. 实现 `app/src/main/java/com/gordon/mypotato/ui/statistics/StatisticsFragment.kt`
- 改为使用 `FragmentStatisticsBinding`。
- 在 Fragment 中维护当前显示模式：
  - `DAY`
  - `MONTH`
  - `YEAR`
- 初始化页面时完成以下逻辑：
  - 绑定切换按钮点击
  - 渲染默认 `DAY` 视图
  - 更新 KPI、区块标题和内容显隐
- 采用静态假数据驱动页面，不依赖数据库。

#### 3.1 Fragment 内部最小数据模型
- `StatisticsMode`
  - 表示 `DAY / MONTH / YEAR`
- `SummaryStats`
  - 字段：`focusMinutes`、`completedCount`
- `DailyTimelineItem`
  - 字段：`timeLabel`、`taskTitle`、`categoryName`、`colorRes`、`isEmpty`
- `StackBarItem`
  - 字段：`label`、`segments`
- `CategorySegment`
  - 字段：`name`、`minutes`、`colorRes`

#### 3.2 日视图规则
- 默认进入 `DAY` 模式。
- KPI 展示“当日总专注分钟”和“当日完成数”。
- 主体用纵向时间轴表达一天 48 个半小时片段。
- 最小实现建议：
  - 只在 Fragment 中生成完整 48 个时间点数据
  - 有任务的时间点显示彩色块 + 任务名 + 类别名
  - 无任务的时间点显示淡色细线或弱化占位块
- 时间轴内容由 Fragment 动态向容器中添加行 View，不额外引入 RecyclerView，降低最小实现复杂度。

#### 3.3 月视图规则
- 切换到 `MONTH` 时：
  - KPI 改为本月总专注时间、本月完成数
  - 隐藏日时间轴容器
  - 显示堆叠图容器
- 图表横轴为本月每天，例如 `1` 到 `30/31`。
- 每天使用一根堆叠柱表示各类别专注分钟。
- 若无类别区分，则该柱子只使用单一默认颜色。

#### 3.4 年视图规则
- 切换到 `YEAR` 时：
  - KPI 改为本年总专注时间、本年完成数
  - 图表横轴改为 `1月` 到 `12月`
- 每月使用一根堆叠柱表示当月各类别专注分钟。
- 图表结构与月视图复用同一套 View，只是横轴标签与数据粒度不同。

### 4. 新增轻量自定义图表 View
- 新增一个简单的自定义 View，例如：
  - `app/src/main/java/com/gordon/mypotato/ui/statistics/StatisticsStackBarView.kt`
- 职责：
  - 接收 `List<StackBarItem>`
  - 绘制浅色网格线
  - 绘制堆叠柱
  - 绘制横轴标签
- 设计原则：
  - 只覆盖当前最小实现需要的能力
  - 不追求通用图表组件
  - 颜色、文字、线条均从主题或资源派生，兼容深浅色

### 5. 可选的时间轴行布局资源
- 为保持代码清晰，建议新增一个日时间轴行布局，例如：
  - `app/src/main/res/layout/item_statistics_timeline_slot.xml`
- 每行包含：
  - 左侧时间文本
  - 右侧内容容器
  - 有任务时显示标签块
  - 无任务时显示占位线
- 如果实现时发现单独 layout 过重，也可在 Fragment 中直接创建简单行视图；但推荐单独 layout，后续更易维护。

## Assumptions & Decisions
- 按用户确认，本次不做周视图，只做 `日 / 月 / 年`。
- 年视图堆叠图按“月汇总”展示，而非全年逐日展示。
- 日视图采用“完整半小时纵向时间轴”，不是仅展示发生过任务的时间段卡片。
- 数据全部使用静态假数据，重点是展示结构、切换和视觉表达，不承担真实统计职责。
- 不引入 MPAndroidChart 或其他第三方依赖，避免最小实现扩散为基础设施改造。
- 月/年图表仅实现最小堆叠柱表达，不附带交互提示、滑动缩放或复杂坐标轴。

## Verification Steps
1. 打开统计页默认进入 `日` 视图，看到标题、切换按钮、KPI 卡片和纵向时间流。
2. 点击 `月`：
   - KPI 数值与标题变化
   - 时间流区域隐藏
   - 堆叠图和图例显示
3. 点击 `年`：
   - KPI 数值与标题变化
   - 图表横轴标签变为 `1月` 到 `12月`
4. 深色/浅色主题下确认：
   - 卡片背景、文字、网格线、柱图颜色保持可读
5. 检查以下文件无新增诊断错误：
   - `StatisticsFragment.kt`
   - `fragment_statistics.xml`
   - 新增的自定义图表 View
   - `strings.xml`
