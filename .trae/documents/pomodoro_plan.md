# 番茄钟页面及逻辑实现计划

## 摘要

根据提供的设计图，实现 `activity_pomodoro.xml` 的 UI 布局，并在 `PomodoroActivity.kt` 中编写对应的番茄钟倒计时基础逻辑。

## 当前状态分析

* **UI 布局**：`activity_pomodoro.xml` 目前仅为一个包含占位文本的简单 `LinearLayout`。

* **业务逻辑**：`PomodoroActivity.kt` 仅重写了 `onCreate` 方法并加载了占位布局，缺乏计时器状态管理和 UI 更新逻辑。

* **技术基础**：项目已集成 Material Components，支持使用 `MaterialCardView`、`CircularProgressIndicator`、`MaterialButton` 等现代组件来实现设计图中的卡片、圆形进度条和圆角按钮。

## 拟议变更

### 1. 页面布局重构 (`activity_pomodoro.xml`)

* **根布局**：采用 `ConstraintLayout`，便于实现各模块的相对定位。

* **顶部导航栏**：

  * 左侧返回按钮、居中标题“番茄钟”、右侧放置静音和更多操作占位图标。

* **当前任务卡片**：

  * 使用 `MaterialCardView`，背景设为白色。

  * 内部包含：“当前任务”提示、编辑图标、任务标题“完成项目原型设计”。

  * 标签行：包含“工作”、“长时任务”、“紧急”（红色背景）、“重要”（黑色背景）等状态标签。

  * 任务描述文字：“设计Todo应用的主要页面和交互流程”。

* **番茄钟计时区域**：

  * 顶部显示状态文字“🍅 专注工作”。

  * 居中放置 `CircularProgressIndicator`（尺寸调大，红色指示器，浅红/粉色背景轨道）。

  * 圆形进度条中心通过布局叠加（`ConstraintLayout`）显示：“专注时长 25 分钟”、大号倒计时文字“25:00”、以及底部胶囊状的“🍅 第 1 个番茄钟”。

* **操作按钮区域**：

  * “开始/暂停”按钮：黑色背景、白色文字，高度饱满的 `MaterialButton`。

  * “重置”按钮：带有灰色边框的轮廓样式 `MaterialButton`。

* **今日进度卡片（底部）**：

  * `MaterialCardView`，包含标题“今日番茄钟进度”和右侧的“1/5 ↑”。

  * 5 个表示进度的圆形指示器（第一个为红色实心带数字1，其余为带边框的空心圆）。

  * 底部提示文字：“完成 5 个番茄钟，休息更长时间”。

### 2. 逻辑实现 (`PomodoroActivity.kt`)

* **状态管理**：定义计时器状态枚举（例如 `IDLE`, `RUNNING`, `PAUSED`）。

* **倒计时实现**：使用 `CountDownTimer`，总时长设定为 25 分钟（1500000 毫秒）。

* **UI 更新逻辑**：

  * 每次 tick 回调时，计算剩余时间并格式化为 `MM:ss`，更新大字文本。

  * 同步更新 `CircularProgressIndicator` 的进度。

* **交互逻辑**：

  * **开始/暂停按钮**：点击时切换状态。若在 `IDLE` 或 `PAUSED`，则启动/恢复计时，并改变按钮文字为“暂停”；若在 `RUNNING`，则暂停计时器，按钮文字变回“开始”。

  * **重置按钮**：点击后取消当前计时器，重置状态至 `IDLE`，UI 恢复为 25:00 和 0 进度。

* **代码规范遵循**：

  * 遵守“最小功能原则”，代码轻量化，全部写在当前 Activity。

  * 在核心方法（如 `startTimer`, `pauseTimer`, `resetTimer`）中优先使用卫语句。

  * 方法注释严格按照模板：方法功能描述、入参、出参、异常。

  * 方法的入口与出口处添加 `Log.d` 或 `Log.i` 打印日志，保证链路可追溯。

## 假设与决策

* 页面数据（如任务名称、标签、当前番茄钟进度）暂时使用**硬编码**，与设计图保持完全一致。后续真实场景中可通过 Intent 传入。

* 未提供具体的返回图标、静音图标和编辑图标时，将使用 Android 系统自带的或简单的文本/图形占位。

* 考虑到简单逻辑的需求，计时器将直接在 Activity 生命周期内运行。页面销毁时将取消计时器以防内存泄漏。

## 验证步骤

1. **静态检查**：核对 `PomodoroActivity.kt` 中是否包含标准的中文注释和出入口日志。
2. **UI 验证**：编译运行项目，进入番茄钟页面，核对界面元素（卡片、圆形进度条、按钮、进度指示器）是否高度还原设计图。
3. **功能验证**：

   * 点击开始按钮，确认倒计时数字和进度条正常走动。

   * 点击暂停按钮，确认倒计时停止。

   * 点击重置按钮，确认倒计时恢复至初始状态 25:00。
