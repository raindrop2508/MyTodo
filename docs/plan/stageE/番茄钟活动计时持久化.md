# 番茄钟活动计时持久化（Issue #9 收尾确认版 + 冷启动续计）

> 更新日期：2026-09-18  
> 状态：已实现（本阶段）  
> 关联：GitHub Issue #9、[Issue #14](https://github.com/raindrop2508/MyTodo/issues/14)、[Issue #15](https://github.com/raindrop2508/MyTodo/issues/15)、[PR #17](https://github.com/raindrop2508/MyTodo/pull/17)  
> 权威详述：[StageD_番茄钟计时持久化_实际落地方案](../stageD/StageD_番茄钟计时持久化_实际落地方案.md)

## 目标

在 Stage D1「会话历史落库」之上，补齐活动计时字段持久化；冷启动时对残留活动会话做用户确认（收尾或续计）。本文件为摘要；相对 `main` 的对照与文件清单见 Stage D 详述。

## 已实现

1. **Room 字段扩展**（`pomodoro_session`，DB version 3，destructive，无 Migration）

| 列名 | 含义（摘要） |
|------|----------------|
| `phase` | 当前阶段：`0` FOCUS / `1` SHORT_BREAK / `2` LONG_BREAK |
| `planned_duration_ms` | 本阶段计划时长（ms） |
| `target_end_epoch_ms` | 运行中目标结束墙钟（epoch ms）；暂停/终态为 `NULL` |
| `remaining_ms_when_paused` | 暂停时剩余倒计时（ms）；运行中/终态为 `0` |
| `pause_started_at_epoch_ms` | 本次暂停开始墙钟（epoch ms）；未暂停/终态为 `0` |

完整含义、写入时机与既有字段衔接见 [StageD 落地方案 §2.1.1](../stageD/StageD_番茄钟计时持久化_实际落地方案.md#211-v3-新增字段含义权威)。

2. **运行中先落库再计时**  
   - 开始 / 暂停 / 继续 / 重置 / 完成写入 Room  
   - 全库活动会话（`IN_PROGRESS` + `PAUSED`）≤ 1  
   - 开始新会话前打断其它活动行
3. **阶段机修复**：休息结束后回到 `FOCUS`；仅专注完成增加 `cycleCount`
4. **专注时长**：按墙钟流逝减暂停计算，避免双重扣减；`COMPLETED` 会话的 `focusDurationSec` 存实际专注秒
5. **冷启动收尾与续计**（`MainActivity`，`savedInstanceState == null`；#14 + #15）  
   - 多条活动行：旧的自动 `INTERRUPTED`，弹窗处理最新一条  
   - **继续计时** → 打开 `PomodoroActivity`（`resumeSessionId`）→ `PomodoroViewModel.resumeActiveSession` 续跑或保持暂停  
   - 专注且已计 > 0：还可「保留时长」→ `COMPLETED`（**不改 Task/Step**）或「不保留」→ `INTERRUPTED`  
   - 专注已计 = 0 / 休息：不继续则「结束」→ `INTERRUPTED`  
   - 结算后之后计时一律新开会话；**不**静默续跑、**不**自动跳转

## 明确不做（后置）

- 杀进程后**静默**恢复倒计时（无弹窗确认）并继续跑表
- 冷启动后**自动**跳转到未完成番茄钟页
- Foreground Service / AlarmManager / 到点通知
- 正式 DB Migration（发布前再补）

## 关键类型

- `PomodoroPhase`：FOCUS / SHORT_BREAK / LONG_BREAK
- `SessionStatus`：IN_PROGRESS / PAUSED / COMPLETED / INTERRUPTED
- `PomodoroTimerLogic`：阶段流转、时长计算、`estimateRemainingMs`（续计剩余）
- `OrphanPomodoroSettlement`：冷启动 Prompt 与保留/丢弃结算
- `PomodoroViewModel.resumeActiveSession`：用户确认后的会话 hydrate 与续跑

## 统计口径

仅统计 `phase == FOCUS` 且 `status == COMPLETED` 的会话专注时长。
