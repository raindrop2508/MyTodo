## 一、模型设计原则

1. **类型约束**：ID 使用 `Long`，枚举使用 `Int`，时间戳使用 `Long`（秒）
2. **纯业务实体**：Stage B 阶段的领域模型为纯 Kotlin 数据类，无 Room 注解
3. **最小字段集**：先定义满足当前 UI 需求的最小字段，后续按需扩展
4. **可空性明确**：区分必填字段与可选字段

## 二、核心实体定义

### 2.1 Task（任务）

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|---------|------|
| id | Long | 必填 | 任务唯一标识 |
| title | String | 必填 | 任务名称 |
| content | String | 可选 | 任务内容描述 |
| note | String | 可选 | 备注信息 |
| taskType | Int | 必填 | 任务类型：0=单次（ONCE）默认，1=长时（LONG） |
| status | Int | 必填 | 任务状态：0=未开始（TODO）默认，1=进行中（IN_PROGRESS），2=已完成（COMPLETED），3=已归档（ARCHIVED） |
| isUrgent | Boolean | 必填 | 是否紧急（四象限维度） 默认为否|
| isImportant | Boolean | 必填 | 是否重要（四象限维度） 默认为否|
| categoryId | Long | 必填 | 所属分类 ID，关联 Category 默认为 0 表示 未分类 |
| createdAt | Long | 必填 | 创建时间戳（秒） |
| plannedStartAt | Long? | 可选 | 计划开始时间戳（秒） |
| finishedAt | Long? | 可选 | 实际完成时间戳（秒） |
| totalDurationSec | Long | 必填 | 累计用时（秒），长时任务有效 |

**四象限映射：**

| 象限 | isUrgent | isImportant | 说明 |
|------|----------|-------------|------|
| 第一象限 | true | true | 紧急且重要 |
| 第二象限 | false | true | 重要但不紧急 |
| 第三象限 | true | false | 紧急但不重要 |
| 第四象限 | false | false | 不紧急且不重要 |

---

### 2.2 TaskStep（任务步骤）

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|---------|------|
| id | Long | 必填 | 步骤唯一标识 |
| taskId | Long | 必填 | 所属任务 ID，关联 Task |
| title | String | 必填 | 步骤名称 |
| sortOrder | Int | 必填 | 排序序号，用于步骤排序 |
| status | Int | 必填 | 步骤状态：0=未完成（TODO）默认为 0，1=已完成（COMPLETED） |
| completedAt | Long? | 可选 | 步骤完成时间戳（秒） |
| spentDurationSec | Long | 必填 | 步骤累计时长（秒） 默认为 0 |
| createdAt | Long | 必填 | 创建时间戳（秒） |

---

### 2.3 Category（分类）

0 为 未分类 作为保留值，不用于实际分类。

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|---------|------|
| id | Long | 必填 | 分类唯一标识 |
| name | String | 必填 | 分类名称（如：学习、工作、生活、健康、购物） |
| colorHex | String | 必填 | 分类颜色十六进制值（如：`#FF6B6B`） |
| iconName | String | 可选 | 分类图标资源名称（如：`ic_category_study`） |

---

### 2.4 PomodoroSession（番茄钟会话）

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|---------|------|
| id | Long | 必填 | 会话唯一标识 |
| taskId | Long | 必填 | 关联任务 ID |
| stepId | Long? | 可选 | 关联步骤 ID（在步骤上下文启动时填写） |
| startedAt | Long | 必填 | 会话开始时间戳（秒） |
| endedAt | Long? | 可选 | 会话结束时间戳（秒） |
| focusDurationSec | Long | 必填 | 工作时段时长（秒） 默认为 0|
| breakDurationSec | Long | 必填 | 休息时段时长（秒） 默认为 0|
| cycles | Int | 必填 | 完成的番茄钟轮次数 默认为 0|
| status | Int | 必填 | 会话状态：0=进行中（IN_PROGRESS）默认为 0，1=完成（COMPLETED），2=中断（INTERRUPTED） |

---

### 2.5 StatisticsCache（统计缓存，可选）

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|---------|------|
| id | Long | 必填 | 缓存唯一标识 |
| dayKey | String | 必填 | 日期键（格式：yyyy-MM-dd） |
| metricType | String | 必填 | 指标类型（如：task_completion_rate、step_completion_rate） |
| payloadJson | String | 必填 | 缓存数据 JSON |
| updatedAt | Long | 必填 | 更新时间戳（秒） |

## 三、实体关系图

```
┌─────────────┐     1:N     ┌─────────────┐
│  Category   │ ──────────► │    Task     │
│  (分类)     │             │   (任务)    │
└─────────────┘             └──────┬──────┘
                                   │
                    ┌──────────────┼──────────────┐
                    ▼              ▼              ▼
              ┌──────────┐  ┌──────────────┐  ┌──────────────────┐
              │ TaskStep │  │PomodoroSession│ │StatisticsCache   │
              │ (步骤)   │  │ (番茄钟会话)  │ │ (统计缓存，可选) │
              └──────────┘  └──────────────┘  └──────────────────┘
```

**关系说明：**
- Category 1:N Task（一个分类包含多个任务）
- Task 1:N TaskStep（一个任务包含多个步骤）
- Task 1:N PomodoroSession（一个任务可产生多个番茄钟会话）
- TaskStep 1:N PomodoroSession（通过 stepId 可选关联）

## 四、枚举值定义

### 4.1 TaskType（任务类型）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | ONCE | 单次任务（如：买东西、回消息），不可启动番茄钟 |
| 1 | LONG | 长时任务（如：背单词），可启动番茄钟 |

### 4.2 TaskStatus（任务状态）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | TODO | 未开始 |
| 1 | IN_PROGRESS | 进行中 |
| 2 | COMPLETED | 已完成 |
| 3 | ARCHIVED | 已归档（可选） |

### 4.3 StepStatus（步骤状态）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | TODO | 未完成 |
| 1 | COMPLETED | 已完成 |

### 4.4 SessionStatus（番茄钟会话状态）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | IN_PROGRESS | 进行中 |
| 1 | COMPLETED | 完成 |
| 2 | INTERRUPTED | 中断 |
