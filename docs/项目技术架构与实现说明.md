## 1. 项目概述

### 1.1 项目定位

MyPotato 是一款基于 Android 原生开发的番茄钟 TODO 应用，融合四象限优先级管理与番茄工作法，帮助用户聚焦重要任务。

**当前实现口径（2026-10）：**

- Stage A–E 主线完成：UI → Repository/ViewModel → Room → 番茄钟/统计 → 深色 / i18n / JSON 备份 / 空态与关键单测
- 活动计时持久化已落地（DB v3）：运行中/暂停中会话字段落库 + 冷启动孤儿收尾与用户确认续计（#14 / #15）
- 运行时仅使用 `Room*Repository`；备份为 `RoomBackupRepository`；统计为 `RoomStatisticsRepository`；`Fake*Repository` 已从工程移除

### 1.2 技术栈总览

| 技术领域 | 选型 | 说明 |
|---------|------|------|
| 开发语言 | Kotlin | 100% Kotlin |
| UI 框架 | ViewBinding + XML + Material 3 | `viewBinding` / `dataBinding` 均已开启 |
| 导航 | Jetpack Navigation Component | 底部 4 入口；深层页为独立 Activity |
| 架构模式 | 单 Activity + 多 Fragment + MVVM | 页面级 ViewModel + `ViewModelFactory` |
| 数据持久化 | Room 2.x | DB `potato_db` **version = 3**，5 张表 |
| 响应式状态 | Coroutines + Flow / StateFlow | DAO Flow → Repository → ViewModel → UI |
| 构建工具 | Gradle + Version Catalog | `gradle/libs.versions.toml` |
| 最低 SDK | API 29 | minSdk = 29 |
| 目标/编译 SDK | API 36 | targetSdk = compileSdk = 36 |
| 图表 | 自定义 `StatisticsStackBarView` | Stage D 计划评估 MPAndroidChart，尚未引入 |

## 3. 架构设计

### 3.1 整体架构

```
UI (Fragment/Activity)
        │
        ▼
ViewModel (StateFlow)
        │
        ▼
Repository 接口
        │
        ▼
Room*Repository → DAO (Flow) → potato_db (v3)
```

- `MainActivity`：底部导航容器；冷启动时通过 `OrphanPomodoroSettlement` 处理残留活动会话（收尾或确认后续计）
- 一级页：Today / Tasks / Statistics / Settings（Fragment）
- 深层页：`TaskDetailActivity` / `TaskEditActivity` / `PomodoroActivity`（Intent 传参）

### 3.2 导航

```
MainActivity
├── Today (startDestination)
├── Tasks
├── Statistics
└── Settings

独立 Activity：
├── TaskDetailActivity  ← taskId
├── TaskEditActivity    ← taskId（新建/编辑）
└── PomodoroActivity    ← taskId（+ 可选 stepId）
```

参数传递：Fragment 间可用 Safe Args；深层 Activity 以 Intent extras 为主，风格并存。

### 3.3 数据层

**数据库：** `AppDatabase`，名 `potato_db`，**version = 3**，开发期 `fallbackToDestructiveMigration`。

| 表 | Entity | 要点 |
|----|--------|------|
| `app_info` | `AppInfo` | 库元信息 |
| `task` | `TaskEntity` | 四象限、类型、状态、外键 Category |
| `task_step` | `TaskStepEntity` | 级联删除 Task |
| `category` | `CategoryEntity` | 名称唯一索引 |
| `pomodoro_session` | `PomodoroSessionEntity` | 关联 Task/Step；含活动计时字段（见下） |

**`pomodoro_session` 活动计时字段（DB v3 新增）：**

| 列名 | 含义 |
|------|------|
| `phase` | 计时阶段：`0` FOCUS / `1` SHORT_BREAK / `2` LONG_BREAK |
| `planned_duration_ms` | 本阶段计划时长（毫秒） |
| `target_end_epoch_ms` | 运行中墙钟目标结束时刻；暂停/终态为 `NULL` |
| `remaining_ms_when_paused` | 暂停时剩余倒计时（毫秒） |
| `pause_started_at_epoch_ms` | 本次暂停开始墙钟时刻；未暂停为 `0` |

权威字段说明（写入时机、与 `focus_duration_sec` / `paused_duration_sec` 衔接）：[StageD_番茄钟计时持久化_实际落地方案](plan/stageD/StageD_番茄钟计时持久化_实际落地方案.md) §2.1.1。

**会话状态：** `SessionStatus` = `IN_PROGRESS(0)` / `COMPLETED(1)` / `INTERRUPTED(2)` / `PAUSED(3)`  
**阶段：** `PomodoroPhase` = `FOCUS` / `SHORT_BREAK` / `LONG_BREAK`

**默认数据：** `DatabaseInitializer` 在 `MyPotatoApp` 启动时写入默认分类与演示任务（若库为空）。

**依赖注入方式：** `ViewModelFactory.getInstance(context)` 内创建 `RoomTaskRepository` / `RoomCategoryRepository` / `RoomPomodoroRepository`（无 DI 框架）。

## 4. 核心页面实现（当前）

> 以下描述对齐当前代码，不再沿用 Stage A 的内联 Mock 口径。

### 4.1 MainActivity

- 绑定 `BottomNavigationView` ↔ `NavController`
- 主题由 `AppPreferences` / `MyPotatoApp` 在启动时设置（不再强制浅色）
- `savedInstanceState == null` 时检查孤儿番茄钟会话：可「继续计时」跳转计时页，或保留/丢弃收尾

### 4.2 Today

- `TodayViewModel` + `TaskRepository` / `CategoryRepository`
- 四象限 Chip 筛选、列表勾选完成、FAB → `AddTaskBottomSheetHelper` 新建并落库
- 点击任务跳转 `TaskDetailActivity`

### 4.3 Tasks

- `TasksViewModel`：搜索 + 类别/象限/状态维度筛选
- 与 Today 共用统一数据源与列表项布局
- FAB 新建任务同链路落库

### 4.4 TaskDetail / TaskEdit

- `TaskDetailViewModel`：按 `taskId` 观察任务与步骤；长时任务可进番茄钟；单次任务隐藏入口并说明原因
- `TaskEditViewModel`：编辑标题/类型/分类/步骤等并写回 Repository；分类 Chip 由 `CategoryChipHelper` 动态生成

### 4.5 Pomodoro

- `PomodoroViewModel`：读取设置页时长；阶段机；开始/暂停/继续/重置/完成均落库
- 全库活动会话 ≤ 1；开新会话前打断其它活动行
- 专注时长按墙钟减暂停计算；仅专注完成增加 cycle；休息结束后回到 `FOCUS`
- 非长时任务：`isValidTask = false`，拒绝计时
- 冷启动续计：`resumeSessionId` → `resumeActiveSession`（进行中开表 / 暂停保持 / 剩余到期走阶段完成）

### 4.6 Statistics（已接真数据）

- 入口在底部导航；`StatisticsViewModel` 订阅 `RoomStatisticsRepository.observe()`
- 维度：时间 / 任务。周期：今日、本周（周一起）、本月、全年
- 只统计 `TODO` / `IN_PROGRESS` / `COMPLETED`。已完成按 `finishedAt` 落入周期，未开始与进行中按 `createdAt`。已归档不计入。完成率 = 已完成 / 三态合计
- 时间维度（非全年）：完成环、已完成趋势柱、完成率 / 平均耗时 / 最长连续
- 时间维度（全年）：53 周热力图（可横向滑动）、完成率 / 日均完成 / 最长连续、三态占比
- 任务维度：分类完成率（超过 5 个可折叠）、四象限完成率
- 聚合在 `StatisticsAggregator`，单测见 `StatisticsAggregatorTest`
- 周期内三态合计为 0 时显示空态文案
- 原 Stage D 计划中的 MPAndroidChart、番茄钟时段堆叠、逾期口径未落地；当前页以 Ardot 统计稿和上述三态为准

### 4.7 Settings

- `SettingsViewModel` + SharedPreferences：专注/短休/长休/长休间隔、提醒开关、主题、语言
- 主题：系统 / 浅色 / 深色（`AppCompatDelegate.setDefaultNightMode`）
- 语言：跟随系统 / 中文 / English（`AppCompatDelegate.setApplicationLocales`）
- 数据管理：SAF 导出/导入 JSON；清空后按 Initializer 再灌默认分类；逻辑在 `RoomBackupRepository` + `BackupJsonCodec`
