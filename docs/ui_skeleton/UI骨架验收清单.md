# UI 骨架验收清单

本清单用于在不依赖数据库与业务逻辑的前提下，对 UI 骨架的“结构完整性、规则落点、可演示性”做阶段验收。

## Stage A：MVP 体验定义（先 UI 骨架）

### A1. 导航结构

- [x] 存在底部导航的 4 个入口：Today / Tasks / Statistics / Settings
- [x] 顶部 AppBar（Top App Bar）在 4 个入口页标题正确且一致
- [x] 深层页面（Task Detail / Task Edit / Pomodoro）具备返回路径（Back 行为可预期）

### A2. Today 页骨架

- [x] 顶部展示日期与问候语区域（可先用占位文案）
- [x] 快速筛选 UI 存在：全部 / 单次 / 长时（不要求功能生效）— 实际：维度为四象限（全部/紧急且重要/重要/紧急/其他），无单次/长时筛选
- [x] 任务列表按四象限分组的结构可见（不要求真实排序）— 实际：列表平铺渲染（按完成状态排序），未按象限分组 （考虑移动视图，四象限不平铺展示）
- [x] FAB 新建入口可见，点击有占位反馈
- [x] 空态存在且提供“新建任务”引导

### A3. Tasks 页骨架

- [x] 顶部 Tab：按类别 / 按四象限 / 按状态（不要求功能生效）
- [x] 筛选区控件存在：类别、任务类型、日期范围（不要求功能生效）— 实际：维度为 类别/象限/状态，缺任务类型与日期范围
- [x] 列表项支持展示步骤摘要区域（可用假数据）
- [x] 空态存在且有引导

### A4. Statistics 页骨架  

统计页后续还需要确定展示内容，留至其他功能完善后最后开发。

- [x] 顶部筛选存在：日/周/月、类别、任务类型（默认仅长时的 UI 意图明确）— 实际：时间文案为今日/本周/本月但映射到 DAY/MONTH/YEAR；类别默认选"全部"；无独立任务类型筛选
- [x] 模块 A/B/C 的容器结构存在（可以是卡片占位）
  > 实际偏差：仅模块 A（时间段分布图表卡）与模块 B（完成情况概览卡片）存在，模块 C（类别步骤完成时间）容器缺失。
- [ ] 模块 A 空态/说明明确写出：仅统计长时任务/步骤— 实际：无口径说明文案，无空态视图

### A5. Settings 页骨架

- [x] 主题模式入口存在：跟随系统/浅色/深色
- [x] 语言入口存在：跟随系统/简体中文/English
- [x] 数据管理入口存在：导入/导出/清空（危险操作需二次确认占位）— 实际：仅有"导出数据"入口，缺导入与清空(数据库建立后开发)
- [x] 关于入口存在：版本号、检查更新占位

### A6. 关键规则落点（必须验收）

- [x] 单次任务（One-time Task）在 Task Detail 中不可启动番茄钟（入口禁用或隐藏 + 原因说明明确）
- [ ] Statistics 模块 A 的口径表达明确：单次任务不纳入时间段统计— 实际：无"单次任务不纳入统计"口径表达

## Stage B：核心流程跑通（假数据优先）

### B1. 数据与状态

- [ ] 引入 Fake Repository 提供任务、步骤、类别的假数据
- [ ] Today/Tasks/Task Detail/Task Edit 的数据来源统一（避免页面各自造数据）

### B2. 三条主流程（可演示闭环）

- [ ] 新建任务：Today -> Task Edit（taskId 为空）-> 保存 -> 返回刷新
- [ ] 编辑任务：Task Detail -> Task Edit（taskId 有值）-> 保存 -> 返回刷新
- [ ] 标记完成：列表页完成操作后状态即时可见（不要求落库）

### B3. 导航参数与回传

- [ ] Task Detail 接收 taskId 正常
- [ ] Task Edit 支持 taskId 可空逻辑
- [ ] 返回后列表能刷新（可用 SavedStateHandle 或共享 ViewModel）

### B4. 规则一致性

- [ ] 单次任务在任何入口无法进入 Pomodoro（包含异常路径的兜底提示）
- [ ] Statistics 的默认筛选仍然倾向“仅长时”
