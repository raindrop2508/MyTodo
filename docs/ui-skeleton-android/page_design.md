# Todo APP 全页面设计规范（Android Material3 + XML）

> 适用场景：Android 原生开发、Material 3 设计语言、纯 XML 布局、深浅色模式适配、四页 + 新增任务弹窗完整 UI 落地规范

## 一、全局通用视觉风格

### 1. 色彩体系

- 设计基准：**Material 3 动态色彩**，优先跟随系统取色，内置静态兜底色值

- 主色（Primary）：`#7C3AED` 紫堇色

- 次要色（Secondary）：`#EC4899` 玫瑰粉

- 中性色系

  - 页面背景 Surface：浅色`#FFFFFF` / 深色`#121212`
  - 卡片 / 列表背景 Surface Variant：浅色`#F5F5F5` / 深色`#1E1E1E`
  - 主文字 On Surface：浅色黑 / 深色白
  - 辅助文字 On Surface Variant：浅灰 / 深灰

  

- 功能色

  - 错误 Error：`#EF4444`
  - 成功 Success：`#10B981`

  

### 2. 排版规范

统一使用 Android 原生 Roboto 字体，遵循 M3 字体层级：

表格







|      元素       |    样式层级     | 字号 sp | 字重 |
| :-------------: | :-------------: | :-----: | :--: |
|   页面大标题    | Headline Medium |   28    | 700  |
| 卡片 / 列表标题 |  Title Medium   |   18    | 500  |
| 按钮 / 菜单文字 |   Label Large   |   14    | 500  |
|  正文辅助文字   |   Body Small    |   12    | 400  |
| 输入框提示文案  |   Body Medium   |   14    | 400  |

### 3. 控件统一规则

1. 圆角：所有卡片、输入框、按钮统一 **16dp**

2. 阴影：普通卡片 `elevation=2dp`，FAB 悬浮按钮 `elevation=6dp`

3. 点击反馈：全局原生水波纹 `?attr/selectableItemBackground`

4. 单位：全部使用 dp /sp，禁止固定 px

5. 边距标准

   - 页面外边距：16dp
   - 控件垂直间距：8dp / 16dp
   - 列表项内边距：水平 16dp、垂直 12dp

## 二、Today 今日页面

### 1. 页面定位

核心首页，展示**当日全部待办**，突出时效性、快速勾选完成、极简操作。

### 2. 整体布局结构

1. 顶部：Material3 Toolbar 导航栏（页面标题）
2. 次顶部：日期栏 + 今日完成统计（已完成 / 总数）
3. 主体区域：当日任务 RecyclerView 列表
4. 空状态：无任务时居中展示空图标 + 提示文案
5. 右下角：圆形 FAB 新增任务按钮

### 3. 视觉 & 交互细节

- 日期栏：展示「年月日 星期」，右侧实时展示今日完成率

- 任务列表项

  - 左侧 M3 圆形复选框，选中自动标绿 + 标题删除线
  - 任务标题 + 次要时间备注（超时文字标红）
  - 支持侧滑操作：右滑删除、左滑切换完成状态

  

- 空页面：浅灰色插画 + 弱化提示文字

- FAB：M3 悬浮按钮，主色背景，点击唤起新增任务弹窗

### 4. 技术布局要点

- 根布局：`ConstraintLayout`
- 沉浸式状态栏适配 `fitsSystemWindows="true"`
- 列表占满剩余空间，约束在顶部栏与 FAB 之间

## 三、Tasks 全部任务页面

### 1. 页面定位

全量任务管理页，支持**搜索、多条件筛选、分类、批量操作**。

### 2. 整体布局结构

1. 顶部：Toolbar + 右上角功能菜单
2. 搜索区：M3 圆角搜索输入框（带搜索图标、清空按钮）
3. 筛选标签栏：TabLayout（全部 / 未完成 / 已完成 / 已过期）
4. 主体：全任务列表 RecyclerView
5. 空状态：无搜索结果 / 无任务占位页

### 3. 视觉 & 交互细节

- Tab 标签：选中下划线主色高亮，文字变色，横向可滚动
- 搜索框：实时模糊检索，无结果展示友好提示
- 列表项：相比今日页，增加**分类彩色标签**
- 长按触发批量选择模式，支持批量删除、批量标记完成
- 顶部菜单：提供清除已完成、分类管理入口

### 4. 技术布局要点

- 组合控件：`TextInputLayout` 搜索框 + `TabLayout` 筛选栏
- 列表复用适配器，多状态筛选动态过滤数据源

## 四、Stats 数据统计页面

### 1. 页面定位

数据可视化页面，展示任务完成趋势、效率统计、分类占比。

### 2. 整体布局结构

1. 顶部：标准 Toolbar 标题栏
2. 时间筛选：按钮切换组（日 / 周 / 月）
3. 数据卡片：三合一指标卡片（完成率、总任务、逾期数）
4. 趋势图表：折线图（每日完成趋势）
5. 占比图表：饼图（任务分类占比）

### 3. 视觉 & 交互细节

- 切换按钮组：M3 单选 Toggle 样式，选中主色填充

- 统计卡片：圆角卡片容器，数据大字突出，指标小字辅助

- 数据色彩逻辑

  - 完成率优秀：绿色、普通：主色、偏低：红色
  - 逾期数量统一红色警示色

  

- 图表样式：柔和配色、透明度填充、适配深浅色模式

- 无数据时图表区域隐藏，展示空数据提示

### 4. 技术布局要点

- 卡片容器：`MaterialCardView`
- 图表依赖：MPAndroidChart 适配 M3 主题色
- 数据动态刷新：切换时间维度自动重绘图表

## 五、Setting 设置页面

### 1. 页面定位

应用配置中心，包含外观、通知、缓存、账号、关于等基础配置。

### 2. 整体布局结构

1. 顶部：标准 Toolbar

2. 头部：用户信息卡片（头像 + 账号信息）

3. 设置列表：分组式条目布局

   - 深色模式开关
   - 任务提醒设置
   - 缓存清理
   - 关于应用 / 版本信息

   

4. 整体滚动：外层嵌套滚动布局，适配小屏

### 3. 视觉 & 交互细节

- 账号卡片：圆形头像、圆角卡片阴影，点击进入账号管理
- 设置条目：独立圆角区块、分割间距、统一水波纹点击
- 开关控件：M3 `SwitchMaterial`，选中主色标识
- 次级页面：带右侧箭头标识，点击跳转二级设置
- 弹窗确认：清理缓存、高危操作使用 M3 标准弹窗

### 4. 技术布局要点

- 根布局：`NestedScrollView` 滚动容器
- 纯 XML 线性 + 约束组合布局，不依赖系统 Preference
- 全局主题监听，深色模式实时无缝切换

## 六、新增任务 BottomSheet 弹窗

### 1. 页面定位

轻量化快速创建任务，底部弹出弹窗，无需跳转页面，操作高效。

### 2. 整体布局结构

1. 弹窗顶部：标题文案

2. 输入区域

   - 任务标题（必填输入框）
   - 截止时间选择器
   - 任务分类下拉选择
   - 多行备注（选填）

   

3. 底部操作栏：取消 / 确认添加 双按钮

### 3. 视觉 & 交互细节

- 弹窗形态：M3 BottomSheet 底部滑入动画，顶部圆角 16dp

- 表单校验：标题为空时，确认按钮触发红色错误提示

- 时间选择：点击唤起系统日历 + 时间选择器

- 分类下拉：悬浮菜单选择，支持自定义分类

- 按钮区分

  - 取消：浅灰次要按钮
  - 确认：主色强调按钮

  

- 关闭逻辑：点击外部 / 返回键关闭，未保存内容二次确认

### 4. 技术布局要点

- 容器：`BottomSheetDialog` 标准 M3 底部弹窗
- 输入控件：全套 `TextInputLayout` +  Material 输入框
- 内容超出时内部嵌套滚动，防止小屏遮挡

------

## 七、全局开发约束（必遵守）

1. 全部布局使用 **AndroidX + Material 3 官方控件**
2. 颜色全部引用主题属性 `?attr/colorXXX`，禁止硬编码色值
3. 所有图标使用 Material Design 矢量图，统一 tint 染色
4. 深浅色模式全覆盖，UI 元素自动适配
5. 控件层级、阴影、圆角、间距严格统一，保证 App 视觉一致性
